Writing your own strategy

A strategy is one small Python class. You compute indicators once, then decide at every candle’s close whether to buy, sell, or get out. If you can write a few if statements, you can write a strategy.

Where to write it

  • In the Lab: Strategies → New strategy opens a fully commented template in the editor. Copy on a built-in strategy gives you its code to change. Upload .py takes a file you wrote elsewhere. Check runs the file on 1,600 test candles and makes sure it doesn’t look into the future; Save keeps it in your account, and it appears in the Backtest list under “My strategies”.
  • In the project folder (to make it built-in for every account): see the end of this page.

The smallest complete strategy

from indicators import sma
from strategy import Param, Strategy


class AboveAverage(Strategy):
    key = "above_average"            # unique id (letters, digits, _)
    label = "Above the average"      # the name shown in the Lab
    description = "Long while the close is above its moving average."
    params = [Param("length", "Average length (candles)", 50, 2, 1000, 1)]

    def prepare(self, d):            # once, before the first candle
        self.c = d.c
        self.avg = sma(d.c, self.p.length)

    def on_bar(self, i, pos, orders):   # at the close of every candle i
        if i < self.p.length:
            return                   # the average isn't ready yet
        if pos is None and self.c[i] > self.avg[i]:
            orders.buy(tag="Above")
        elif pos is not None and self.c[i] < self.avg[i]:
            orders.exit("Below")

That is all a strategy needs. It has no stop, so the report can’t measure it in R and the position size falls back to “a % of the account”; real strategies usually set a stop (next sections).

Lengths. Give every indicator length unit="candles". The backtest form then lets you type it in candles, minutes, hours, days or weeks (an “EMA of 35 days” on 1h candles becomes 840 candles), suggests sensible values for the timeframe, and shows how long that is. Your code always receives candles in self.p.length.

Warm-up. warmup= says how many lengths of history the indicator needs before its value can be trusted, so the backtest loads that much data before the first trade: WINDOW (1×) for indicators that look at exactly the last n candles (sma, highest, donchian, …), EMA (4×) for exponential averages, whose start value fades out slowly, and WILDER (8×) for Wilder smoothing (rsi, atr, adx), which fades even more slowly. The strategy’s warm-up is the largest of these, plus one candle; the form shows it next to the settings and it changes as you type. When a value is built from several settings (MACD’s signal line runs on top of its slow EMA), override it:

def warmup(self, interval_ms):       # candles of history needed before the first trade
    return 4 * (self.p.slow + self.p.signal) + 1

prepare(self, d): compute indicators

Runs once. d holds the candles as numpy arrays: d.o d.h d.l d.c d.v (open, high, low, close, volume) and d.t (open times in milliseconds, UTC). Also len(d), d.interval (“4h”) and d.interval_ms (its length in milliseconds), d.symbol, d.market (“futures”/“spot”) and d.extra.get("tbv") (taker-buy volume, Binance datasets only). Futures data with funding rates also has d.extra.get("funding_t") and d.extra.get("funding_r"): every funding payment’s time (ms) and rate, for the whole file; use only payments up to the candle’s close (d.t[i] + d.interval_ms). Store what you need on self.

on_bar(self, i, pos, orders): decide

Runs at the close of every candle i, in order. Use index i and earlier only. pos is None when flat, otherwise the open position:

pos.…
side1 long, −1 short
entry_px, entry_ifill price (with slippage) and the candle it filled on
stop, targetcurrent stop and target (None if not set)
qty, levsize in coins, and leverage used at entry
stop0, risk0the first stop, and the money it risked (1R)

Orders

CallWhat happens
orders.buy(...) / orders.sell(...)Enter long / short with a market order at the next candle’s open. Ignored while a position is open, unless you also call orders.exit() in the same candle (that reverses the position).
orders.buy_stop(price, valid=n, ...)Enter long if the price trades up to price within the next n candles (a breakout entry). sell_stop is the short version.
orders.buy_limit(price, valid=n, ...)Enter long if the price dips to price (a pullback entry). sell_limit is the short version.
orders.exit("why")Close the position at the next open; “why” shows in the trade list.
orders.set_stop(price), orders.set_target(price)Move the open position’s stop or target (for example a trailing stop).
orders.cancel()Cancel a waiting stop/limit entry. orders.pending shows it.
orders.last_exit_iThe candle on which the last trade closed (to avoid re-entering at once).

Options for every entry: stop=price or stop_dist=distance; target=price or target_r=multiple of the stop distance; max_bars=n to close after n candles; tag="text". A stop on the wrong side of the entry is refused (the report counts it as skipped).

The one rule: never look ahead

At candle i you only know candles 0…i. Using self.c[i + 1], a centred average, d.c.max() over the whole history, or anything computed from future candles makes a backtest look wonderful and is worthless live. Check catches this: it changes the future candles and fails the file if anything the strategy computed or decided up to that point changes.

Finding mistakes

  • Check shows Python errors with the line they happened on.
  • print(...) inside your strategy shows under the report (“Printed by the strategy”), up to 400 lines. Print sparingly, for example only when a trade opens.
  • If a strategy makes no trades, test a shorter setting or print the indicator at a few candles.

Recipes

A trend filter

def prepare(self, d):
    self.c = d.c
    self.r = rsi(d.c, 14)
    self.trend = ema(d.c, 200)
    self.atr = atr(d.h, d.l, d.c, 14)

def on_bar(self, i, pos, orders):
    if i < 200 or pos is not None:
        return
    if self.r[i - 1] < 30 <= self.r[i] and self.c[i] > self.trend[i]:   # dip in an up-trend
        orders.buy(stop_dist=2 * self.atr[i], target_r=2, tag="Dip in up-trend")

A breakout entry with a stop order

def on_bar(self, i, pos, orders):
    if pos is None and i > 20:
        level = self.high20[i]                         # highest high of the last 20 candles
        orders.buy_stop(level, valid=1, stop=self.low20[i], tag="Breakout")

A trailing stop

def on_bar(self, i, pos, orders):
    if pos is not None and pos.side > 0:
        trail = self.c[i] - 3 * self.atr[i]
        if trail > pos.stop:                           # only ever move it up
            orders.set_stop(trail)

Don’t re-enter on the candle a trade closed

if orders.last_exit_i == i:
    return

Making a strategy built-in

To give every account a strategy (and keep it with MEDUSA’s code):

  1. Put the file in medusa/public/lab/strategies/, for example my_idea.py.
  2. Add its file name to medusa/public/lab/strategies/index.json.
  3. Optional: write a page for it as medusa/public/lab/docs/<key>.html and add it to the BUILTIN list at the top of medusa/public/lab/learn.js.
  4. Deploy: npx wrangler@4 deploy in the medusa folder.

The engine files themselves are in medusa/public/lab/py/ (engine.py, indicators.py, strategy.py, stats.py); a new indicator added to indicators.py is available to every strategy after the next deploy.
