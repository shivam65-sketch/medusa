Getting data

A data file is one coin on one timeframe over a period of time. Get it from Binance in one of two ways, then backtest it. Every file you keep on MEDUSA can be deleted again in the Files tab.

Either way, the files on MEDUSA stay until you delete them (Files tab, one at a time or a whole folder), so you can use them for a single test and remove them straight after. The upload form also has Delete the file from MEDUSA after the backtest, which keeps only the result.

Choosing the coin

Click one of the popular coins, or type any coin Binance trades in USDT (the box suggests them as you type, for example PEPEUSDT or 1000PEPEUSDT on futures). The page warns if Binance doesn’t list the name on the market you picked.

Futures or spot?

Futures (USD-M perpetuals) can go long and short, with leverage, and pay or receive funding; tick Include funding rates to download the real funding history with the candles. Spot is buying the coin itself: backtests on spot data take long trades only, at 1x, without funding.

Timeframe and how far back

  • Timeframe is how much time each candle covers, from 1 minute to 1 week. Bigger timeframes are cheaper to trade (fewer trades, each aiming for a bigger move than the costs); 1h and 4h are good places to start.
  • How far back: 1, 2, 3 or 5 years, All time (since Binance listed the coin; BTC futures from September 2019, BTC spot from 2017), or custom dates.
  • Before downloading, the page shows how many candles that is and how big the file will be, and it stops you if it’s too many: up to 1,000,000 candles for MEDUSA and backtests, up to 2,000,000 for a file on your computer.

Only finished candles are downloaded; the one still forming is left out. The dates you pick are midnight in your time zone. Files keep the exchange’s UTC times; MEDUSA shows them in your time zone. Downloading the same coin, timeframe and dates again finds the copy already in your Downloads folder instead of storing it twice.

The file on your computer

The name says what’s inside, for example BTCUSDT-futures-1h-2021-10-04-to-2026-10-04.csv, so the upload form can fill in the coin, market and timeframe by itself.

  • ZIP (smaller): the candles as a CSV, plus a second CSV with the funding rates if you downloaded them. Upload the ZIP as it is to keep funding in your backtests. Windows and macOS open it with a double-click.
  • CSV: the candles only, one line per candle; opens in Excel or Google Sheets.

Uploading a file to backtest it

Drop the file on Upload a file and backtest it (or choose it). Besides MEDUSA’s own files, it reads:

  • Binance’s archive files (BTCUSDT-1h-2024-01.zip from data.binance.vision), as they are; several monthly files of one coin are joined.
  • CSV files with a header line naming a time column (time, timestamp, date or open_time) and open, high, low, close, optionally volume. Times can be Unix seconds, milliseconds or dates like 2024-01-31 16:00 (read as UTC). TradingView’s “Export chart data” files work.
  • CSV files without a header in Binance’s column order: time, open, high, low, close, volume, …

Then it asks:

  1. What is this data? The coin, futures or spot, and the timeframe of each candle. It detects the timeframe from the gaps between candles and warns if your choice doesn’t match.
  2. Which dates? All of the file, or part of it (a backtest takes up to 1,000,000 candles; only these dates are saved on MEDUSA).
  3. Which strategy? Any built-in strategy or one of yours, with its settings.
  4. Costs, money and checks (optional): fees, starting money, risk per trade, leverage, a held-back date.

Upload and backtest saves the file in the Uploads folder, runs the test and shows the result on the Dashboard (saved in the Results folder). You can run more strategies on the same file from the Dashboard afterwards.

How files are stored on MEDUSA

Candles are compressed in your browser before they are saved: each price column is stored as whole numbers with its own number of decimals, as differences from the previous candle. Prices come back exactly as Binance published them (the Lab’s tests compare every value), in about a fifth of the size of a CSV. The Downloads, Uploads and Results folders share Cloudflare’s free storage (1 GB for the whole app); the top bar of the Lab and the Files tab show how much is left.
